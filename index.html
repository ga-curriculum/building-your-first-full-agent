The Mission Brief

Meet ContentPilot

You're building ContentPilot — a Content Assistant agent that helps creators, marketers, and entrepreneurs generate post ideas, write summaries, draft LinkedIn posts, build Twitter/X threads, and craft content hooks. It receives a topic and audience, thinks about platform and tone, and produces structured, actionable output.

Agent Specification Brief
What It Does
🖊 Generates 5–7 specific post ideas on any topic
📝 Writes TL;DR summaries from long text
💼 Drafts LinkedIn posts in a professional voice
🧵 Builds structured Twitter/X threads
🪝 Crafts attention-grabbing content hooks
Success Criteria
✅ Output is immediately usable — no editing required
✅ Tone matches the stated platform
✅ Ideas are specific, not generic (no "Write about AI")
✅ Format is scannable and structured
✅ Responds in under 8 seconds
👤 Primary User Personas
Creator/SolopreneurPosting 3–5x/week, needs ideas fast. Values specific, non-generic outputs they can publish immediately.
Marketing ManagerRepurposing long-form content into social. Values format consistency and platform-appropriate tone.
EntrepreneurBuilding thought leadership. Values outputs that sound like them, not a generic AI chatbot.
⚠️ Design Constraints
Tone: Adaptable to creator's voice. Default = professional but human, not corporate.
Length: Post ideas ≤ 30 words each. LinkedIn ≤ 250 words. Hooks ≤ 25 words.
No fluff: Never output phrases like "Great question!" or "In today's digital landscape..."
No hallucination: If given a summary task with no input text, ask for the text before proceeding.
💡 The agent design philosophy: ContentPilot is a thinking partner, not a ghostwriter. Its job is to give the creator raw material they can react to, edit, and personalize — not produce polished copy they post unchanged. Outputs should be 80% of the way there, not 100%.

The Agent Spec Document

A prototype without documentation is a dead end. The spec document is what makes ContentPilot reproducible, improvable, and handoffable. Fill out all 6 sections — this is the artifact you'd give an engineering team to implement and a QA team to test against.

💡 Good specs are falsifiable. Every claim in your spec should be testable: "The agent produces 5–7 post ideas, each 10–30 words, with a specific angle and a hook element" is a spec. "The agent produces helpful content" is not.
